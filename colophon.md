This site is deliberately small. It's a static [Jekyll](https://jekyllrb.com) site, built
by GitHub Pages straight from the default branch — no framework, no build pipeline, no
`node_modules`. The same principle I hold for everything else: **native over special.**

### Type

The identity is set in **Futura**; body text in a smooth, high-legibility serif
(*Iowan Old Style*, falling back to *Charter* then *Georgia*). Metadata and code are
**Menlo**. Every face is a system font — the page carries no webfont, so it loads
instantly and looks like itself on the first paint.

### Color

One paper, one ink, and a single **signal red** <span class="sq"></span> — rationed to a
handful of jobs so it always means *look here*. Light and dark are both first-class; the
toggle up top remembers your choice and otherwise follows your system.

### Elsewhere

Code lives on [GitHub](https://github.com/alxjrvs). The source for this site is
[alxjrvs.github.io](https://github.com/alxjrvs/alxjrvs.github.io).
