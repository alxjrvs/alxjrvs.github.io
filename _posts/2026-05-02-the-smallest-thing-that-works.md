Every project starts with a temptation to build the version that handles everything. The
smallest thing that works is almost always better: it ships, it's legible, and it tells
you what the second version actually needs to be.

## Ship the sketch

A sketch you can use beats a blueprint you're still drawing. The gaps in a working sketch
are honest — they're the features you genuinely miss, not the ones you imagined missing.

> Build the version you can throw away, and you'll rarely have to.

The rest is subtraction. Once the smallest thing works, the interesting question is never
"what else can I add" — it's "what can I take out and still have it stand."
